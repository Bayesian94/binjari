학생 명단

모델 API

Gemini · OpenAI · Claude · Upstage

키는 이 브라우저에만 저장됩니다. 공용 PC에서는 사용을 마친 뒤 [키 삭제]를 눌러 주세요.

서버 없는 구조라 API 키는 암호화된 비밀이 아닙니다. 제한된 데모용 키를 사용하세요. 기본 설정에서는 키를 선택한 서비스에만 전송합니다. 고급 endpoint를 바꾸면 그 주소로 전송되므로 신뢰할 수 있는 주소만 사용하세요. 학생 원문 대신 학생 ID·후보 ID·고정 분류 신호만 전송됩니다.

서비스를 고르고 키 값만 붙여넣으세요. 복사된 Authorization: Bearer, 따옴표, 공백·줄바꿈은 자동으로 제거합니다. 모델 목록 확인은 키 저장과 별개이며, 실제 사용 가능 여부는 연결 시험에서 확인합니다.

고급 연결 설정

브라우저 CORS가 모델 목록 조회를 막으면 공식 기본 모델을 제시하고 연결 시험에서 실제 권한을 확인합니다. 연결에 실패해도 모든 화면은 규칙 기반으로 계속 동작합니다.

시연과 데이터

별칭·모둠·출석번호가 모두 부여된 가상 학생 25명과 가상 관찰 메모를 불러옵니다. 기존 《빈자리》 데이터는 교체됩니다.

다운로드한 HTML을 직접 열 때 브라우저 저장 정책이 달라도 복원할 수 있도록 작업 백업을 보관하세요. 백업에는 학생 자료가 포함되며 API 키는 제외됩니다.
